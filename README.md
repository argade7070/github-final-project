# Simple Interest Calculator App

A Java application that calculates simple interest based on user-provided principal, rate, and time.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

## Prerequisites

- Java Development Kit (JDK) 8 or higher installed
- Verify with: `java -version`

## How to Run

**1. Compile the Java program:**

```bash
javac SimpleInterestCalculator.java
```

**2. Run the application:**

```bash
java SimpleInterestCalculator
```

## Usage

When prompted, enter:
- **Principal** – the initial amount of money
- **Rate** – annual interest rate (in %)
- **Time** – duration in years

The program will output the calculated Simple Interest.

## Example

```
Enter Principal: 1000
Enter Rate: 5
Enter Time: 3
Simple Interest = 150.0
```

# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for considering contributing to this project. This document outlines the guidelines for contributing.

## Code of Conduct

By participating in this project, you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting Bugs

Open an issue with a clear title, the steps to reproduce the problem, the expected behavior, and the actual behavior.

## Suggesting Enhancements

Open an issue describing the enhancement or idea and why it would be useful.

## Submitting Changes

1. Fork the repository and create a new branch for your change.
2. Follow the coding style and conventions used in the existing codebase.
3. Test your changes thoroughly before submitting.
4. Open a pull request with a clear description of what you changed and why.

## Documentation

Improvements to the README and other documentation are always appreciated. Keep explanations clear and concise.

By contributing, you agree that your contributions will be licensed under the [Apache License 2.0](LICENSE).

Thank you for your contribution!
